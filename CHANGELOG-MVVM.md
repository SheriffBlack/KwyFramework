# Kwy MVVM Changelog

All notable changes to the `Kwy.MVVM` and `Kwy.MVVM.WPF` product line are documented here.

The product line follows Semantic Versioning. During the `0.x` release cycle, public APIs may change between minor versions.

## [0.1.0] - Unreleased

Initial public preview.

### Included

- MVVM commands and observable infrastructure
- Dependency injection integration
- Message bus and WPF message dispatching
- Module catalog and module lifecycle
- Navigation contracts and WPF region navigation
- Dialog contracts and WPF dialog service
- View-model location and view caching
- Authorization abstractions and WPF permission integration

### Compatibility

- `Kwy.MVVM`: .NET 8.0
- `Kwy.MVVM.WPF`: .NET 8.0 for Windows
